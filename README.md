## Overview

**Bloodroot** is an OSINT project built around the concept of efficient digital intelligence gathering. It aims to provide a centralized environment for researching publicly available information, examining digital footprints, and organizing investigative findings.

Designed with simplicity, functionality, and extensibility in mind, Bloodroot aims to make reconnaissance workflows more accessible and organized.

## Features

- **Information Gathering** — Collect and organize publicly available intelligence.
- **Digital Footprint Analysis** — Examine publicly accessible online presence.
- **Username Research** — Investigate username availability and public associations.
- **Domain Intelligence** — Research domains and publicly available domain information.
- **Email Intelligence** — Analyze publicly accessible email-related information.
- **IP Intelligence** — Explore publicly available IP and network information.
- **Modular Architecture** — Designed for future tools and integrations.

## Installation

Clone the repository:

```bash
git clone BloodRoot
```

Navigate to the project directory:

```bash
cd BloodRoot
```

Install the required dependencies according to your environment:

```bash
pip install -r requirements.txt
```

Start the application using the appropriate command for your implementation.

```bash
python3 osint.py -h
```

## Usage

1. Launch Bloodroot in your environment.
2. Select the intelligence module you want to use.
3. Provide the relevant publicly available information.
4. Execute the investigation.
5. Review and organize the collected results.
